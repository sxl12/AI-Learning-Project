# 项目名称

## 项目介绍

角色扮演,设定角色为李白和叶瑶，可以根据需求在config.yaml文件中进行修改，。

## 目录结构

Role-Play
.
├── src/                        # 源代码目录
│   ├── start_chat.py           # 主程序文件
│   ├── utils/                  # 工具目录
│   │   ├── __init__.py         # 初始化文件
│   │   └── config_loader.py    # 加载配置文件
        └── meta_info.py        # 构建menta
        └── chat_util.py        # 构建client
└── README.md             # 项目说明文档

运行项目
在 Role-Play/chat 目录下运行
python start_chat.py
